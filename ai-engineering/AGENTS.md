# AI Engineering 网站维护规则

本文件只补充本目录的维护约定，不覆盖仓库或用户全局规则。

- 先读 `project.json` 恢复当前目标、优先级依据、当前单元、证据与下一步。它是项目状态的唯一维护源。
- 三条基础主线是评估与测量、Agent 运行及信息状态、模型与数据机制。模型适配属于综合应用，工作迁移属于验收；不要恢复成固定四阶段课程。
- 优先级是可修订的判断，不能写成已证明的职业最优路线。区分用户明确缺口与尚未检验的知识深度。
- 不把概念、作者 prompt 或 Skill 用法预设为有价值。需要对应的机制理解、实验或实际采用证据。
- AI 生成了材料或代码，不等于使用者已经掌握。不得代答后更新个人完成状态。不要制造评分、百分比或已运行实验。
- `lesson-01.md` 是可跳过的参考，不是强制学习入口。新的工作应围绕真实学习目标更新 `current`，而不是扩充独立 issue-list。
- 内容修改优先只动 `project.json`。保持纯静态、相对路径和无外部运行依赖；不要为维护站点建设 Eval 平台。
- 浏览器草稿是本地临时材料。正式进展必须经核对后写入 `project.json`；Library / Taskbook 导出仅为版本快照。
- 运行与改动相称的检查：JSON 有效、关键导航/筛选/导出、移动端无水平溢出、无控制台错误。资料版本在实际实验时核对。
